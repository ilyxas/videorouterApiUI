## Текущая поставка

Workflow состоит из Steps с DAG карточек и Continue/Pause между Steps. Image/Video/Audio наследуют BaseCard по типу output. Типизированные связи работают внутри Step и из предыдущих Steps. Режимы переключаются в карточке, дополнительные параметры доступны через API Explorer с возвратом в workflow. Добавлен шаблон точного двухэтапного acceptance.

Steps можно удалять и переставлять с сохранением порядка зависимостей, переключать между Cards и Flow. Flow показывает квадраты с миниатюрами и стрелками слева направо, карточки имеют чередующийся фон. Запуск и результаты остаются в редакторе. Отключённые Steps используют последний или закреплённый успешный output без API-вызова и повторного расхода; без output пропускаются. Зависимые карточки с недостаточными входами пропускаются с причиной. Во время run доступны будущие enabled и Continue/Pause; на паузе — редактирование любого Step, выбор прежнего output и отдельная перегенерация кнопкой «Запустить Step». Продолжение использует выбранные outputs пройденных Steps.

References передаются URL/data URI без обязательного внешнего upload; предусмотрен fallback для больших файлов и URL-only API. Сохранены предварительные оценки, точная оценка перед генерацией, история, drafts, прежние workflow и данные. V1 сохраняется отдельно при миграции. Pause/resume не повторяет завершённые Steps.
