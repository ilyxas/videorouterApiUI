# Исправление оценки, моделей и формата · 2026-11-17

> Последнее исправление функций; история запуска процессов и обязательный replan перед продолжением этапа 4 дополнены в [09](09-current-state-and-next-thread.md). Здесь перечислены результаты проверок, а не подтверждение полной приёмки пользователем.

Исправляет проблемы поставки 07, обнаруженные пользователем. Утверждение о завершённости UX оценки в предыдущем отчёте было преждевременным.

- Предварительная оценка теперь собирается из одного выбранного шага. Не компилирует всю цепочку, не требует заполненного prompt, загрузки файлов или результата предыдущего шага. Неразрешённые связи и локальные file IDs не отправляются в API оценки: показано, какие входы пропущены. Никаких placeholder URL или автоматических upload/generation.
- Проверка полноты остаётся у запуска; перед изображением/видео цена уточняется по фактическому разрешённому запросу. В предварительной оценке изменённые допущения показываются вместо ошибки. Если цена зависит от отсутствующих данных и API возвращает cannot_estimate, показывается ответ API; числовая стоимость не выдумывается.
- Причина null у GPT Image 1: API по умолчанию выбирало quality=standard, отсутствующее среди low/medium/high. Общая нормализация задаёт medium и 1024×1024, если пользователь не задал другое; эти же значения видны в форме и отправляются при генерации.
- В Image добавлены видимые селекты модели, формата (для GPT Image — квадрат/портрет/альбом с размерами) и качества. Для других семейств используются aspect_ratio/resolution; DALL·E имеет свои размеры/quality.
- Убраны узкие списки из одной Image-модели и семейства LTX. Используются endpoint/type/capabilities каталога вместе с сохранёнными описаниями действий. Сервер и UI инициализируют один реестр статическими и загруженными строками каталога. Отрицательные capability-флаги учитываются; одиночный аудиовход по документации остаётся LTX-only. Пустое поле аудиофайла больше не ограничивает список видео этим семейством.
- Известные профили сохраняют специальные ограничения. Для остальных каталожных моделей форма предлагает общие параметры endpoint, без заявления, что каждая комбинация размеров поддерживается моделью. Фактические ограничения проверяются API оценки/генерации; неподдерживаемые размеры API может заменить своими defaults.

## Проверки

22 автоматических теста проверены частями: модульные/UI-функции, две интеграции с локальным транспортом и затронутые проверки после исправления пустого audio picker. Все прошли. Новые проверки: цена отдельного изображения при незаполненных соседних шагах; одинаковые size/quality в оценке и отправке; неполный video input; реальные альтернативы в списках; новые live catalog rows и отрицательные capabilities; пустой/заполненный audio picker.

Один проход браузера с настоящим API оценки через изолированную копию. Транспорт позволял только `/pricing/estimate`, генерации и загрузки были заблокированы:

- GPT Image 1 без prompt, 1024×1536 / medium: $0.064575.
- Переключение на DALL·E 3, 1024×1024 / standard: $0.041.
- Выбор fal/seedance-2.0 из списка Video: $1.554925 за 5 секунд / 720p / 9:16 без prompt и без готового изображения. Пропущенные входы видны в окне оценки.
- В текущем объединённом каталоге список создания изображений содержал 298 вариантов; у видео доступны в том числе Seedance, Kling, Veo. Это не гарантия стабильного количества моделей.

Всего 6 реальных бесплатных запросов оценки (3 диагностика + 3 браузер). **Расход $0**, генерации не выполнялись. Тестовый relay не включён в рабочую поставку.
