| Endpoint / действие | Модель | Контракт Studio |

Video reference/edit/extend/motion-control/upscale отключены с причинами. Ограничения берутся из реестра `public/contracts.mjs`, а не выводятся из названий тарифов. Старые неподдерживаемые значения остаются видны и требуют исправления; автоматического снижения разрешения или удаления входа при смене модели нет.

## Реализация

- Один контракт используется формой, компилятором и сервером (preflight и после разрешения связей). Управляемые шаги передают `contractMode`; отдельные advanced-запросы используют raw API.
- Image edit/upscale принимают выбранный image output по стабильному ID. Компилятор формирует вложенный `input_references`; адаптер разрешает HTTPS/base64, сохраняет явный индекс результата и проверяет известный TTL. Новые шаги вставляются непосредственно после источника.
- При вставке пересчитываются старые positional refs; типизированные связи остаются по ID. Перемещение с нарушением зависимости блокируется.
- Оценка изображения/видео выполняется по разрешённому фактическому запросу. Если API в `assumptions` меняет явно запрошенную duration/resolution/aspect_ratio/n/size/width/height, генерация останавливается. Проверка сравнивает только присутствующие допущения: отсутствие поля в ответе оценки не доказывает фактический размер результата.
- Длительности для проверки отдельных lip-sync профилей вводятся в оценке шага; при изменении источника старые значения не используются. Это пользовательские метаданные, не независимое измерение удалённых файлов.
- Поиск видеомоделей ограничен профилями реестра; несовместимые сохранённые настройки блокируют запуск. Остальные модели можно исследовать через API Explorer.
- Пять карточек имеют краткие заголовки, связи, оценки и верхнюю навигацию. Возврат из параметров сохраняет положение в workflow; контекст сохраняется и в черновике редактора.

## Проверки

17 автоматических тестов выполнены частями: базовые/контрактные, две интеграции на локальных серверах и отдельная проверка смены endpoint в расширенном редакторе. Все прошли. Тестовый транспорт не вызывает реальный API.

Проверено: URL/base64 и выбор второго output; image → edit → upscale → async video; одинаковые параметры оценки и генерации; регрессия 8/5 секунд; остановка при изменённых assumptions; неизвестные модели/параметры/голоса/провайдеры; ошибки источника и оценки; сохранение, reload, вставка, перенос и удаление связанных шагов; серверная preflight-проверка без внешних вызовов; восстановление истории после перезапуска.

Один браузерный проход на изолированном сервере: сборка цепочки и пятого независимого шага; исправление пустого prompt; изменение prompt через расширенный редактор; reload; успешный запуск пяти шагов на фикстурах. На 390 px `scrollWidth=clientWidth=390`; верхняя навигация содержит все пять шагов. Снимок: `evidence/09-stage4-mobile.jpg`.

**Расход реального API: $0.** Платный end-to-end с живыми моделями не выполнялся; совместимость провайдеров подтверждена документацией и локальными контрактными тестами, не качеством сгенерированного медиа. Бюджет $10 не израсходован.
