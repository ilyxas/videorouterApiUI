17 ноября 2026. Выполнен этап 1 плана: сохранность работы.

- Версионированный черновик workflow в localStorage: текст, настройки, asset ID и связи, восстановление после reload. Незавершённый JSON расширенного редактора также восстанавливается. Видны состояние сохранения и ошибка хранилища. Один текущий черновик на origin браузера; именованные workflow сохраняются отдельно существующей кнопкой.
- Стабильные ID пользовательских шагов; старые workflow получают их при открытии. Формат позиционных связей пока сохранён; существующие проверки порядка и удаления зависимостей продолжают работать. Технические операции компилятора сохраняют sourceStepId.
- Новые запуски хранят config.version=1, исходный workflow и скомпилированные шаги. Перед вызовом API сохраняется request с параметрами после разрешения ссылок. В истории доступны конфигурация, фактические параметры и открытие как нового черновика без выполнения. Старые записи явно обозначены как неполные.
- Существующая БД и медиа при внедрении не изменялись; изменения схемы SQLite не требуются. Для серверных изменений нужен обычный перезапуск приложения, когда нет активных заданий.

Тест сервера работает во временной директории, полностью подменяет внешний fetch, проверяет сохранение после перезапуска. Запуск: `node --test tests/persistence.test.mjs`. Проверки браузера на изолированной копии: reload черновика, незавершённого JSON и его исправление. Реальные API-запросы не выполнялись; расходы $0 из разрешённых $10.
